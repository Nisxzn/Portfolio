<h1 align="center">✨ Nisxzn-ULT Portfolio ✨</h1>

<p align="center">
  A futuristic, cinematic, and highly interactive personal portfolio built with React, Vite, Tailwind CSS, and Framer Motion. 
  Experience a premium UI with smooth scroll parallax and dynamic animations that make a lasting impression.
</p>

---

## 🚀 Features

- **Cinematic AI Lab Aesthetic:** A meticulously designed dark-mode user interface with a 6xl container layout.
- **Smooth Parallax Scrolling:** Implemented via `@studio-freight/lenis` for an elevated user experience.
- **Rich Animations:** Interactive and micro-animations crafted with `framer-motion`.
- **Responsive Design:** Completely optimized for desktops, tablets, and mobile devices using Tailwind CSS 4.
- **Contact Integration:** Seamless message delivery powered by EmailJS.
- **Modern Tech Stack:** Fast build and dev server with Vite.

## 🛠️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Nisxzn/Nisxzn-ULT.git
   cd Nisxzn-ULT
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open your browser to the local URL provided (usually `http://localhost:5173`) to view the application.

## 💻 Tech Stack

- **Frontend Framework:** React 18
- **Build Tool:** Vite
- **Styling:** Tailwind CSS 4
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Scrolling:** Lenis Parallax Scroll
- **Emails:** EmailJS
